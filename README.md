### Projects

#### **[Distributed Event & Notification Engine](https://github.com/demmanuel58-spec/event-notification-engine)**
* **What it is:** Multi-service event bus built with FastAPI, RabbitMQ, JWT Auth, and KEDA autoscaling.
* **Why it matters:** Decouples API latency from background notifications using topic exchanges, manual `basic_ack` worker loops, and dead-letter queue (DLQ) containment.
* **Stack:** Python, FastAPI, RabbitMQ, Docker Compose, Kubernetes, KEDA, GitHub Actions.

#### **[TaskPulse](https://github.com/demmanuel58-spec/taskpulse)**
* **What it is:** Asynchronous task queue and relational state machine backed by Redis and PostgreSQL.
* **Why it matters:** Offloads long-running tasks from HTTP routes to sub-50ms responses using exponential backoff retries and DLQ isolation.
* **Stack:** FastAPI, Celery/Redis, PostgreSQL, Docker.

#### **[Campaign Management API](https://github.com/demmanuel58-spec/campaign-management-api)**
* **What it is:** Enterprise API implementing Domain-Driven Design (DDD), soft deletions, and RBAC.
* **Why it matters:** Secures multi-tenant resource access with JWT tokens and detailed audit logging.
* **Stack:** FastAPI, PostgreSQL, SQLAlchemy, Alembic, Docker.

#### **[SysGuard](https://github.com/demmanuel58-spec/sysguard)**
* **What it is:** Lightweight Linux process monitoring and system health daemon.
* **Why it matters:** Captures CPU/memory telemetry and dispatches real-time alerts upon resource threshold breaches.
* **Stack:** Python, Linux CLI, Bash, Docker.
